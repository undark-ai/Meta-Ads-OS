# Questions (Batch)

Run 6 question-framed headline techniques together for a fast, varied batch of ~20 labeled headlines, three or four per technique. Pick the strongest angle for each technique rather than forcing a weak one — variety and quality across the set matter more than hitting an exact count. Label each headline with its technique.

**The 6 techniques:**

1. **Call the Bluff** — challenge an empty claim or assumption the audience holds.
   Example: ABC: "If TV's so bad for you, why is there one in every hospital room?"

2. **Humblebrag** — ask a question that is secretly a flex about the product.
   Example: TestGorilla: "Is this the end of the resume?"

3. **Objections** — voice the reader's skeptical objection, then answer it.
   Example: Monday.com: "Why are you using Monday.com? It's not for developers."

4. **Concierge** — hand the reader the keys and ask what they will do.
   Example: Vercel: "What will you ship?"

5. **Wake-Up Call** — alert the reader to a costly habit they don't realize they're in.
   Example: Fondue: "WTF! You're still using coupons?"

6. **What If?** — paint the better reality the product creates, starting with "what if?".
   Example: Weglot: "What if translating your website was mind-blowingly easy?"

For fuller detail on Wake-Up Call, see [wake-up-call.md](wake-up-call.md).
