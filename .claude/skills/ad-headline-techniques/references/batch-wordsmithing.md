# Wordsmithing (Batch)

Run 17 wordplay and rhetorical techniques together for a fast, varied batch of ~20 labeled headlines, one or two per technique, leaning on the ones that fit best. Pick the strongest angle for each technique rather than forcing a weak one — variety and quality across the set matter more than hitting an exact count. Label each headline with its technique.

**The 17 techniques:**

1. **Metaphor** — say the product is something from a completely different world.
   Example: Evernote: "Your second brain."

2. **Analogy** — compare it to something familiar using "like".
   Example: State Farm: "Like a good neighbor, State Farm is there."

3. **Onomatopoeia** — use a word that sounds like the noise it makes.
   Example: Mazda: "zoom-zoom"

4. **Dialogue** — write it the way a real person would say it out loud.
   Example: Vercel: "The 'wow, this site is fast' Cloud."

5. **Rhyme** — pair words with matching end-sounds.
   Example: Wise: "Join millions saving billions."

6. **Alliteration** — repeat the same starting sound across words.
   Example: Canopy: "Build better B2B lending products."

7. **Anaphora** — repeat the same word at the start of each line.
   Example: Maybelline: "Maybe she's born with it. Maybe it's Maybelline."

8. **Pleonasm** — add a few redundant words on purpose for emphasis.
   Example: FedEx: "When it absolutely, positively has to be there."

9. **Epistrophe** — repeat the same word at the end of each line.
   Example: Las Vegas: "What happens here, stays here."

10. **Asyndeton** — list items with no "and", just commas.
    Example: Jaguar: "Grace, space, pace."

11. **Allusion** — wink at something famous (a movie, a saying, a moment).
    Example: Gatorade: "Be Like Mike."

12. **Parallelism** — repeat the same sentence shape for rhythm.
    Example: Wall Street Journal: "Money talks. We translate."

13. **Oxymoron** — pair two opposite words that still fit.
    Example: Skoda: "Simply clever."

14. **Chiasmus** — flip the same words around in the second half.
    Example: Bounce: "Stops static before static stops you."

15. **Reverse World** — flip the usual point of view to surprise.
    Example: Cancer Patients Aid Association: "Cancer cures smoking."

16. **Rearrange** — scramble letters or shuffle words so the mess makes the point.
    Example: Lego: "EGLO. Unlimited possibilities."

17. **Antithesis** — put two opposites side by side so the contrast sells it.
    Example: Apple: "Small chip. Giant leap."
